# 🌤️ Weather & Outfit Recommender

A modern web application that shows real-time weather data, a 7-day forecast chart, and personalized outfit recommendations based on temperature, humidity, and conditions — with dynamic themes and dark mode.

## 🚀 Features

- 🔍 City search (default: Buffalo)
- 🌡 Switch between Celsius (°C) and Fahrenheit (°F)
- 🎨 Background changes based on time of day (dawn, morning, afternoon, night)
- 🌙 Dark mode toggle
- 🧥 Smart outfit suggestions (rain/snow/humidity aware)
- 📊 7-day temperature forecast chart (Chart.js)
- 📱 Fully responsive for mobile and desktop

## 🛠️ Built With

- **React.js**
- **Chart.js** via `react-chartjs-2`
- **Visual Crossing Weather API**
- **CSS (custom styles)**
